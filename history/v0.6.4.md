# v0.6.4 — 2026-10-10

## Objective

Complete PR03 / F01 and F03 of N679xA scope remediation: effective waveform timing and pretrigger readiness.

## Implementation

- Query SENS:SWE:TINT?, SENS:SWE:POIN? and SENS:SWE:OFFS:POIN? after configuration. Require positive finite effective interval and exact integral point/offset readbacks; failures mark acquisition UNKNOWN.
- Introduce frozen DigitizeTiming metadata with requested/effective interval, actual points, actual offset, and computed pretrigger fill interval. ArrayMeasurement.interval_s reflects actual instrument readback, not requested setpoint.
- wait_digitize_armed confirms WTG_meas, then delays at least abs(negative offset) * effective interval plus configurable 5 ms default guard, starting after WTG status is observed. No fill delay is used for zero or positive offsets.
- A single readiness timeout applies to both status polling and fill, so impossible deadlines error and PR02 verifies abort. Cooperative abort_requested supported. Reconfirm WTG before reporting readiness.
- Extend N6700 wrapper with optional pretrigger_guard_s and abort_requested while preserving existing positional alias support.
- Simulated sweep interval quantization and SCPI readbacks (RES20 / RES40), plus deterministic fake-clock and failure tests.

## References

Keysight N6705C User's Guide, Digitizing Measurements, pages 211–214: supported sample intervals, 512K shared memory, interval rounding and the warning that triggers occurring before the pretrigger count completes are ignored. N6700 Programmer's Reference: SENSe:SWEep:TINTerval?, SENSe:SWEep:POINts?, SENSe:SWEep:OFFSet:POINts?.

## Boundaries / remaining work

- The default 5 ms fill guard is a conservative engineering parameter, not a hardware-qualified timing guarantee. It does not prevent spontaneous analog/external events from occurring before the buffer is ready. HIL repetitions and guard characterization are required by PR08.
- Mainframe-global resolution, shared active measurement parameter count and memory constraints will be handled with PR05. Transport/session concurrency and raw SCPI bypass remain unresolved until PR04.
- The driver's acquisition state is not a substitute for instrument-measured trigger-event timestamp or independent oscilloscope correlation.
- No live instrument was connected or energized by this PR; production scope use still requires subsequent PRs.
