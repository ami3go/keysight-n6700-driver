# v0.7.11 — 2026-10-16

## Scope

Documentation-only release establishing a dedicated `task/` directory and two
post-v0.7.10 Arb task specifications:

- [`task/N6700_ARB_REMAINING_WORK_TASK.md`](../task/N6700_ARB_REMAINING_WORK_TASK.md)
  defines RW-00…RW-09 plus optional RW-10 with independent review, watchdog CI,
  bounded waveform execution, digitizer lease recovery and site-gated HIL/DSO
  tests, evidence schema, uncertainty/guard-band policy and downstream
  Waveform Studio validation.
- [`task/N6700_ARB_REMAINING_QUALIFICATION_TASK.md`](../task/N6700_ARB_REMAINING_QUALIFICATION_TASK.md)
  defines eight sequential packages (ARB-R01 through R08) covering the
  acquisition lease transport-fault defect (#14), capability and core-pin
  verification (#21/#15), supervised waveform lifecycle, protocol coverage, a
  hardware-safe HIL evidence runner, site-authorized DSO acceptance and
  downstream release qualification.

## Changes

- Add `task/README.md` and both task specifications.
- Increment distribution version to 0.7.11 (display/archive 26.25).
- Update plugin manifest, AI-contract identity and SHA-256 integrity lock.
- Retain the immutable `scpi-driver-core` pin at `9c5dd50a03031f65e1aa5cf13832db7372f043b9`.
- Do not change any driver, channel, simulator, transport or SCPI command behavior.

## Explicit limits

No source driver algorithm, safety interlock, SCPI transport, waveform runtime,
hardware tests or analog qualification changed in this release. Actual execution
of each task requires separate implementation PRs and (for physical tests)
documented site/operator approval. The driver remains simulator/software tested,
not qualified for unattended source Arb operation.

## Qualification and CI gates

- [ ] Python 3.10/3.13 CI (Ruff, mypy, pytest, structure, generated-contract freshness).
- [ ] Independent documentation/safety review; no physical hardware used.

These tasks are **not** approval for physical ARB generation. Physical Arb/HIL/DSO
remains unqualified until separately authorized and supported by raw evidence.
