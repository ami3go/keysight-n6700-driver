# v0.6.5 — 2026-10-10

## Scope

Documentation-only update to clarify the built-in scope/digitizing capabilities
of the N6700-series power-system modules, especially Option 054 differences.

## Changes

- Added the mainframe/module digitizer availability table to README.md.
- Documented that the N6705C includes output-list and digitizing functions
  without Option 054, including with the N6775A power-supply module.
- Distinguished module capabilities with N6700C plus N6775A (054 required),
  N676xA precision sources (built in), and N678xA SMUs (built in).
- Explicitly qualified the successful N6700C/N6791A HIL results versus the
  manufacturer's current N6705C-only published load-module compatibility.
- Clarified that the driver digitizing API currently targets ElectronicLoadChannel,
  and referenced the Keysight March 2026 specifications guide.

## Validation and limitations

Documentation, package/manifest versions, and AI-contract lock metadata only;
no hardware test or runtime implementation change. This update does not add a
digitizing API for N6775A, N676xA, or N678xA.
