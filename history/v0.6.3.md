# v0.6.3 — 2026-10-10

## Objective

Remediation PR02: F02, ensure missing trigger or transport/polling failures do not leave a capture silently armed.

## Implemented

- wait_digitize_armed and wait_digitize_complete now attempt ABOR:ACQ on exceptions, including the library timeout and cancellation, and preserve the original exception.
- abort_digitize verifies that WTG_meas and MEAS_active have both cleared using a bounded status-polling deadline; only then does it label a generation ABORTED.
- If abort or its verification fails, the driver marks the acquisition UNKNOWN and reports the cleanup failure on the primary exception's details.
- Reject non-finite, zero and negative timeout arguments before touching the instrument.
- Added unit tests for missed triggers, readiness timeout, operator cancellation, failed idle verification, failed status query and invalid timeout values.

## Limits and next work

Transport-specific per-command timeouts still depend on connect() and scpi-driver-core session configuration. PR03 will add pretrigger-readiness barriers; PR04 will enforce acquisition lease and avoid concurrent buffer modifications; PR08 will qualify with real N6791A hardware. No physical HIL was run in this version.
