# v0.7.10 — 2026-10-16

## Scope

Completes the hardware-free DRV-ARB-B through DRV-ARB-H work after the v0.7.9
capability prerequisite. This is a software/simulator protocol release; no
physical source output was energized and no analog waveform is qualified.

## Safety and protocol changes

- Serialize each source configuration across the shared session and preserve
  the primary exception through independent best-effort cleanup.
- Select channel-scoped `TRIG:TRAN:SOUR` for LIST/STEP and
  `TRIG:ARB:SOUR` for ARB from typed capability data; never emit global `*TRG`.
- Enforce every parametric shape timing field at 262.144 s while retaining the
  N678xA-specific 268.435 s UDEF dwell limit.
- Distinguish ordinary-supply current-limit waveforms from SMU current-source
  waveforms. Negative current is limited to reviewed N678xA two-quadrant
  models in current priority; N6783A and ordinary supplies remain non-negative.
- Read SMU voltage compliance with `VOLT:LIM`, verify range/protection state,
  and keep the other source quantity fixed.
- Bound CDW ASCII uploads to 64 KiB before mutation, never fragment them, and
  verify the instrument-reported point count.
- Preflight sequence memory at the 511 generated-point limit, require finite
  dwell-paced normal completion, and validate `ARB:SEQ:QUAL?` (16–100).

## Dependency and release evidence

- Pin both normal and `[visa]` requirements to reviewed
  `scpi-driver-core@9c5dd50a03031f65e1aa5cf13832db7372f043b9`
  (v0.1.0.dev11).
- Add focused current, CDW, sequence, transaction-lock, trigger-dialect, and
  core byte-fidelity tests.
- Regenerate capability, conformance, plugin-manifest, and AI-contract
  artifacts for distribution 0.7.10.
- Build and verify the wheel and source distribution.

## Qualification boundary

Simulator and offline protocol checks do not establish output accuracy,
bandwidth, trigger latency/jitter, protection performance, or safe unattended
operation. The separately documented DSO/HIL matrix still requires explicit
site/operator authorization, reviewed wiring and limits, and retained raw
measurement evidence.
