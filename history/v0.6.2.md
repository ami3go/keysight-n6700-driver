# v0.6.2 — 2026-10-10

## Scope

First implementation PR of [N679xA scope remediation](../docs/N679XA_SCOPE_REMEDIATION_PLAN.md): **F04** (status-derived false acquisition completion and stale driver generations).

## Implemented

- Added a per-channel `AcquisitionTracker` with generation counter, states IDLE/CONFIGURED/ARMED/WAITING/ACQUIRING/COMPLETE/FETCHED/ABORTED/UNKNOWN, snapshot and guards.
- `configure_digitize` invalidates previous captured evidence, `arm_digitize` increments generation, `wait_digitize_armed` observes WTG_meas, and `wait_digitize_complete` only returns success when this generation has been seen WAITING or ACQUIRING and status indicates no current waiting/active acquisition.
- `trigger_digitize` requires observed readiness; `fetch_digitized_array` rejects any call without a proven completed capture, preventing accidental stale fetch after abort/rearm.
- Simulator records an acquisition generation and completed-buffer state; exposes both waiting and active bits on INIT and clears them on trigger/abort. Array queries reject invalid buffer state.
- Added deterministic unit tests for ambiguous zero status, abort, rearm, stale buffer, illegal ordering and same-generation fetch.
- No SCPI command changes to the tested N6791A real-hardware happy path; backward-compatible wrappers remain in N6700.

## Deliberately not closed

This is **only PR01**. F01–F03 and F05–F14 remain open. In particular, physical provenance under concurrent or external controllers cannot be guaranteed without PR04; an acquisition completing before the first observed waiting/active status may not be provable and should not be reported as complete. Timeout cleanup and readiness barriers require PR02 and PR03. The simulator is still not a waveform-fidelity model. No hardware operations were performed in this release.

## Validation

Run offline tests and build through CI, and approve gated HIL only after verifying the bench safety configuration. Do not advertise production-ready, unattended transients based solely on simulator tests.
