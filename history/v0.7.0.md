# v0.7.0 — 2026-10-14

Implemented bounded source-voltage transients for power-supply and SMU
channels: programmable voltage slew, finite voltage LIST and user-defined ARB
profiles, BUS/external trigger selection, generation-token lifecycle,
WTG/active status polling, bounded timeout abort, and safe-shutdown recovery.

The Python API and Robot Framework adapter share the same validation and
state machine. Configuration requires output OFF, finite points and repeats,
an explicit approved voltage envelope, bounded duration, instrument readback,
and accepted documented dwell quantization. The simulator, offline tests,
capability/AI contracts, and guarded N6775A HIL test cover protocol behavior.

Physical voltage amplitude, dwell, edge rate, overshoot, trigger latency, and
jitter remain unqualified until the independent oscilloscope matrix in
[`docs/VOLTAGE_TRANSIENT_IMPLEMENTATION.md`](../docs/VOLTAGE_TRANSIENT_IMPLEMENTATION.md)
is executed and retained. No real hardware was energized for this release.
