# v0.10.0 — 2026-11-06

## Scope

Feature release on top of v0.9.0: the electronic-load voltage-on (`VOLT:INH:VON`) setter, which
constant-power (CP) profiles need because their worst-case sinking current is
`maximum_level / VON`.

## Changes

- Add `ElectronicLoadChannel.set_load_voltage_on()` / `get_load_voltage_on()` (#42, PR #43). The
  setter validates the value, writes `VOLT:INH:VON`, checks the SCPI error queue and compares a
  readback with the request; a mismatch raises instead of returning an unverified value.
  `SIM_LOAD` refuses it, like the current limit.
- Hardware finding: switching the load mode with `set_load_mode("cp")` resets VON on an N6791A.
  Program VON after the mode switch, then configure the list.

## Verification

- Unit, mypy, ruff, structure validation and artifact freshness pass locally; hosted CI passed on
  PR #43 (Python 3.10 and 3.13).
- Real N6791A (power_supply_test #375, 2026-11-06): VON set, read back and restored; a CP LIST then
  ran with the 1 W step measuring 1.0004 W. Only that one module and one profile were exercised.
