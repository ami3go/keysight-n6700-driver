# v0.8.0 — 2026-10-22

## Scope

Consolidation release for the post-v0.7.10 work. It merges the electronic-load
LIST/ARB feature, DRV-14 terminal transport recovery, the N679-02 exact-depth
digitizer receipt, the v0.6.0 deep-review hardening, and the remaining ARB
task/qualification documentation into one reviewed `main`.

## Changes

- Add N679xA electronic-load LIST and ARB profiles for current, voltage,
  resistance and power, including user-defined and constant-dwell ARB. The
  lifecycle is guarded (input OFF, matching priority mode, verified readbacks,
  bounded sinking-current envelope) and uses the `mainframe_global` trigger
  dialect required by the N6700C.
- Abort load transients before `shutdown_all` switches outputs OFF, and wait
  for the transient system to become idle after an abort.
- Add DRV-14 recovery: a terminal transport fault invalidates only the affected
  digitizer lease; replacement-lease validation is atomic with teardown, and
  shutdown precedes closing host-side state.
- Add the N679-02 exact-depth digitizer configuration receipt and the
  fail-closed `get_verified_digitize_available_points` API. Free-capacity
  support is explicitly not claimed; the methods remain in the conformance
  exclusions pending independent review.
- Port the v0.6.0 deep-review hardening: transactional session lifecycle,
  verified writes/shutdown/output/measurement, SMU limit and protection
  semantics, SCPI parameter validation, safe REAL-block parsing, dynamic
  exception classification, datalog cadence fixes, and non-invasive read-only
  CLI sessions.
- Fix the simulator's `VOLT:LIM` / `VOLT:INH:VON` fallthrough, which could
  report a bogus `LIST:TOUT:EOST` undefined-header error, and add
  `RES:RANG` / `POW:RANG` support for load-range queries.
- Add a basic Tk GUI example for the ARB generator and the v0.7.11 ARB
  remaining-work and qualification task specifications.
- Increment the distribution to 0.8.0 (display/archive 26.26). Refresh the
  plugin manifest, AI-contract identity/SHA-256 lock, capability model,
  protocol inventory, and conformance exclusions.
- Add `scripts/ci_local.sh` so the full GitHub-Actions-equivalent check set can
  be run locally, including generated-artifact freshness.

## Explicit limits

The driver remains simulator/software tested overall. Protocol HIL passed 4/4
on an N6700C (E.02.09.3271) with an N6791A and no source connected; that result
does not qualify sinking accuracy or timing. The N679-02 free-capacity API is
fail-closed and not independently reviewed for release as verified capacity.
Source ARB triggering on the N6700C still uses channel-scoped
`TRIG:ARB:SOUR`, which the bench rejects with `-108`, so it fails closed.
