# v0.6.9 — 2026-10-10

PR07 F11 (large waveform response handling). Added bounded binary-block transfer using the pinned `scpi-driver-core.ScpiClient.query_binary_block`, REAL32 decode in explicit `FORM:BORD SWAP` little-endian mode, exact byte count/finite-value validation, SHA-256 payload digest and restoration of original acquisition format and byte order. Auto mode selects binary for 4,096 or more points; caller can select ASCII/REAL32. Control audit logs response size/hash instead of copying large response payloads; underlying protocol trace sink already caps each recorded payload at 4 KiB. Simulator and offline tests cover the path.

**No hardware validation** of the binary path, VISA framing, resource usage or N6791A firmware differences was performed. PR08 HIL and independent DSO qualification remain required.
