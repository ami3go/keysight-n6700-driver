## v0.1.0 — 2026-09-13

First release of this repository. Ported from the Robot-Framework-first
`rf_keysight_n6700` driver in `ami3go/RobotFrameworks_hw_drivers` into a
Python-first driver with an optional Robot Framework adapter, per the
[Lab pyDrivers Standard](https://github.com/ami3go/Lab-equipment-pyDrivers).
Rebuilt on [`scpi-driver-core`](https://github.com/ami3go/scpi-driver-core)
for transport/SCPI-client plumbing. See
[`history/v0.1.0.md`](../history/v0.1.0.md) for the full record and
[`review/known_risks.md`](../review/known_risks.md) for scope decisions.
